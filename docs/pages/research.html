연구 내용

관련 연구, 시스템 모델, 그리고 TD-MPC2 기반 자원 최적화 프레임워크를 요약한다.

2. 관련 연구

2.1 RSMA 자원 최적화

기존 RSMA 연구는 스펙트럼 효율과 간섭 제어 측면에서 강점을 보여주었지만, 반복적 수치 최적화에 크게 의존하는 경우가 많았다. 따라서 실제 운용 환경에서는 계산량을 줄이면서도 공정성을 함께 고려할 수 있는 구조가 필요하다.

2.2 MLB

MLB는 셀 간 부하 불균형을 완화하기 위한 대표적 기법이지만, 기존 연구는 주로 네트워크 계층 제어에 초점을 맞춰 왔다. 본 연구는 여기에 RSMA의 물리 계층 특성을 함께 반영해 두 계층을 연계하는 방향으로 확장한다.

3. 시스템 모델

3.1 네트워크 및 채널 모델

다중 셀 하향링크 5G MIMO 환경을 가정하고, 사용자 이동성과 셀 간 간섭이 동시에 존재하는 시나리오를 설정했다. 채널은 3GPP 기반 모델과 불완전 CSIT 조건을 반영해 실제 운용 상황에 가깝게 구성했다.

3.2 저복잡도 사용자 선택 기반 RSMA 전송 모델

제안 기법은 모든 사용자를 무겁게 최적화하는 대신, 사용자 선택 단계에서 PF 지표와 채널 공간 상관도를 함께 고려한다. 이를 통해 공통 스트림 병목을 줄이면서도 특정 사용자에게 자원이 과도하게 몰리는 현상을 완화한다.

3.3 A3 기반 핸드오버 모델

네트워크 계층에서는 A3 기반 핸드오버 규칙과 CIO를 사용해 접속 셀을 조정한다. 이는 혼잡 셀의 사용자를 주변 셀로 분산시키는 핵심 수단이며, 핑퐁 현상을 줄이기 위해 안정적인 제어가 필요하다.

3.4 처리량 및 부하 모델

성능 평가는 단순 전송률이 아니라 실제 처리량과 셀별 부하 수준을 함께 본다. 이를 통해 전송 효율과 네트워크 공평성을 동시에 평가할 수 있도록 했다.

3.5 문제 정의

최종적으로 본 연구는 처리량을 높이면서도 부하 불균형을 줄이는 공동 최적화 문제를 정의한다. 즉, 개별 링크 성능이 아니라 네트워크 전체 자원 활용을 더 잘 만드는 방향으로 문제를 설정했다.

4. TD-MPC2 기반 자원 최적화 프레임워크

4.1 멀티 타임스케일 교차 계층 제어 구조

RSMA 분할 비율은 빠르게 조정되어야 하고, CIO는 조금 더 천천히 안정적으로 갱신되어야 한다. 본 연구는 이 차이를 반영해 멀티 타임스케일 제어 구조를 구성했다.

4.2 MDP 정식화

4.2.1 상태 공간

현재 셀 부하, 병목 수준, 제어값 등 네트워크 상태를 함께 관측한다.

4.2.2 행동 공간

에이전트는 RSMA 분할 비율과 CIO를 조절해 전송과 핸드오버를 동시에 제어한다.

4.2.3 보상 함수

처리량과 부하 분산을 함께 반영해 두 성능이 균형 있게 좋아지도록 구성한다.

수식 7 위치

상태 공간, 행동 공간, 보상 함수 요약 PNG 삽입 예정

4.3 TD-MPC2 알고리즘

4.3.1 월드 모델

환경의 변화를 내부적으로 예측할 수 있도록 잠재 공간 기반 모델을 학습한다.

4.3.2 잠재 공간 기반 계획

미래 상태를 미리 시뮬레이션하며 더 안정적인 행동을 선택한다.

4.3.3 네트워크 최적화 및 파라미터 갱신

학습된 정책을 바탕으로 반복적으로 자원 제어 성능을 개선한다.

소개 수준에서 정리하면, TD-MPC2는 시행착오를 줄이면서도 동적인 통신 환경에 맞는 제어 정책을 더 빠르고 안정적으로 찾는 방법이다.
