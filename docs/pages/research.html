연구 내용

2. 관련 연구

2.1 RSMA 자원 최적화

기존 RSMA 연구는 스펙트럼 효율과 간섭 제어 측면에서 강점을 보였지만, 반복적인 수치 최적화에 의존하는 경우가 많았다. 본 연구는 실제 이동 환경에서 계산 부담을 줄이면서도 처리량과 부하 분산을 함께 고려할 수 있는 방향에 초점을 맞췄다.

2.2 MLB

MLB는 셀 간 부하 불균형을 완화하기 위한 대표적인 기법이지만, 주로 네트워크 계층 제어 중심으로 다뤄져 왔다. 본 연구는 여기에 RSMA의 물리 계층 특성을 결합해 교차 계층 관점의 공동 제어 문제로 확장했다.

3. 시스템 모델

3.1 네트워크 및 채널 모델

다중 셀 5G MIMO 환경을 가정하고, 이동 사용자와 셀 간 간섭이 동시에 존재하는 시나리오를 구성했다. 채널은 3GPP 기반 모델과 불완전한 CSIT 조건을 반영해 실제적인 전송 환경에 가깝게 설정했다.

3.2 저복잡도 사용자 선택 기반 RSMA 전송 모델

제안 기법은 모든 사용자를 동시에 최적화하기보다, 사용자 선택 단계에서 PF 지표와 채널 공간 직교성을 함께 고려한다. 이를 통해 공통 스트림 복호 부담을 줄이면서도 자원 집중으로 인한 성능 왜곡을 완화한다.

\[ \mathbf{x}_m = \sqrt{p_{m,c}}\,\mathbf{w}_{m,c}s_{m,c} + \sum_{u \in K_m}\sqrt{p_{m,u}}\,\mathbf{w}_{m,u}s_{m,u} \]

3.3 A3 기반 핸드오버 모델

네트워크 계층에서는 A3 기반 핸드오버 규칙과 CIO를 이용해 접속 셀을 조정한다. 이 과정은 사용자 분산과 실패 핸드오버 억제를 동시에 고려하는 제어 변수로 사용된다.

\[ \mathrm{RSRP}_{n,u} + O_{c,n} - \mathrm{Hys} \ge \mathrm{RSRP}_{p,u} + O_{c,p} + O_{A3} \]

3.4 처리량 및 부하 모델

성능 평가는 단순 전송률이 아니라 사용자 처리량과 셀 간 부하 편차를 함께 본다. 이를 통해 전송 효율과 네트워크 균형을 동시에 반영하는 목적 구성이 가능해진다.

3.5 문제 정의

최종적으로 본 연구는 처리량을 높이면서도 부하 불균형을 줄이는 공동 최적화 문제를 정의한다. 즉, 개별 링크 성능보다 네트워크 전체 자원 사용의 균형을 함께 고려하는 형태다.

\[ \sigma_l = \sqrt{ \frac{1}{|M|} \sum_{m \in M}(l_m-\bar l)^2 }, \qquad J = w_T \tilde{T} + w_L \left(1-\tilde{\sigma}\right) \]

4. TD-MPC2 기반 자원 최적화 프레임워크

4.1 멀티 타임스케일 교차 계층 제어 구조

RSMA 분할 비율은 빠르게 조정하고, CIO는 상대적으로 느린 주기로 갱신하는 멀티 타임스케일 구조를 사용했다. 이는 두 제어 변수의 시간적 특성을 분리해 학습 안정성과 제어 효율을 함께 확보하기 위한 구성이다.

4.2 MDP 정식화

4.2.1 상태 공간

셀 부하, 부하 변화율, 큐 상태, 분할 비율, CIO, 사용자 분포를 상태로 구성했다.

4.2.2 행동 공간

에이전트는 각 셀의 RSMA 분할 비율과 CIO를 함께 조정한다.

4.2.3 보상 함수

처리량과 부하 분산을 함께 반영해 두 성능 지표의 균형을 유도했다.

\[ \mathcal{M} = (S, A, P, r, \gamma), \qquad \mathbf{s}_t = \left[ l(t), \Delta l(t), q(t), \eta(t), c(t), \phi(t) \right] \]

4.3 TD-MPC2 알고리즘

4.3.1 월드 모델

환경의 전이를 잠재 공간에서 예측해 실제 상호작용 부담을 줄였다.

4.3.2 잠재 공간 기반 계획

미래 상태를 예측하면서 더 안정적인 행동을 선택하도록 구성했다.

4.3.3 네트워크 최적화 및 파라미터 갱신

반복적인 업데이트를 통해 제어 정책과 예측 모델을 함께 개선했다.

요약하면 TD-MPC2는 미래 상태를 직접 예측하면서, 빠르게 변하는 무선 환경에 맞는 제어 정책을 찾는 데 초점을 둔 모델 기반 강화학습 방법이다.

\[ \hat{\mathbf{z}}_{t+1} = f_{\theta}(\mathbf{z}_t, \mathbf{a}_t), \qquad \hat{r}_t = r_{\theta}(\mathbf{z}_t, \mathbf{a}_t) \]
