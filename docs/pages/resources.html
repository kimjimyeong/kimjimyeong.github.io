논문 및 추가 자료

논문 파일

최종 제출본 기준의 논문 PDF는 아래 링크로 바로 내려받을 수 있도록 정리한다. 웹페이지에서는 논문 내용을 요약해 소개하고, 원문 확인이 필요한 경우에는 PDF 파일을 통해 전체 내용을 확인할 수 있게 한다.

  • 학위논문 PDF 다운로드

개발 시스템 코드

개발 시스템 코드는 별도 GitHub 저장소 링크로 연결하는 형태가 가장 자연스럽다. 웹페이지 안에 압축 파일을 직접 두기보다, 버전 이력과 파일 구조를 함께 볼 수 있는 저장소 링크를 제공하는 편이 관리와 접근성 측면에서 유리하다.

저장소 주소가 확정되면 이 위치에 GitHub 링크를 연결해, 논문 소개 페이지에서 바로 구현 코드로 이동할 수 있도록 정리한다.

Testing Data

Testing data는 전체 실험 raw data를 그대로 공개하기보다, 재현용으로 필요한 최소 구성만 묶어서 제공하는 편이 적절하다. 이 페이지에서는 논문 결과를 다시 확인할 수 있는 수준의 샘플 입력과 설정 자료를 정리하는 구성을 권장한다.

  • 실험 시나리오와 파라미터를 요약한 설명 파일
  • 재현용 샘플 입력 또는 설정 파일
  • 대표 결과를 확인할 수 있는 예시 출력 또는 로그 일부
  • 실행 방법과 파일 구성을 설명하는 간단한 README

정리 형태는 `testing-data.zip` 한 묶음이 가장 무난하며, 제출용 웹페이지에서는 전체 데이터셋보다는 재현 확인용 샘플 패키지로 구성하는 쪽이 깔끔하다.
